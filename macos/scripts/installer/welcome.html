SwiftX11 — X11 Server for macOS

SwiftX11 is a native macOS X11 protocol server. It allows X11 applications (xterm, xcalc, Vivado, Vitis, and other Linux GUI tools) to display on your Mac using Metal-accelerated rendering.

What gets installed

  • SwiftX11.app → /Applications
  • X11 Fonts (optional) → /opt/X11/share/fonts/
    Standard PCF bitmap fonts for legacy X11 apps. Not needed if XQuartz is already installed.

Quick start

  1. Launch SwiftX11 from Applications.
  2. Add to your shell profile (~/.zprofile or ~/.profile):
    export DISPLAY=127.0.0.1:1
  3. Run an X11 app: xterm, xeyes, etc.
  4. For Docker containers: DISPLAY=host.docker.internal:1

See Help → SwiftX11 Help in the app for full documentation.
